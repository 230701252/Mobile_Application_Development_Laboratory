# Placement Hub - Flutter App

A mobile platform where **seniors** share placement preparation materials and **juniors** can browse, like, comment, save, download, and connect with seniors via chat.

## Features

### Common
- Email/password Login & Signup with role selection (Senior / Junior)
- Role-based home page
- Profile settings
- Notifications
- Connections list
- Real-time 1-on-1 Chat
- Professional white + indigo accent UI with shadowed cards

### Senior
- Upload PDFs / materials
- Share placement experience (text post)
- View incoming connection requests (accept/reject)
- See total uploads, total connections
- Chat with connected juniors

### Junior
- Browse all materials (with search & filter)
- Like, comment, share, save, download PDFs
- View senior profiles
- Send connect requests
- Chat with connected seniors

## Setup Instructions (VS Code + USB Debugging)

### 1. Prerequisites
- Install **Flutter SDK** → https://docs.flutter.dev/get-started/install
- Install **Android Studio** (for Android SDK) or just the command-line tools
- Install **VS Code** + Flutter & Dart extensions
- Run `flutter doctor` and fix any issues

### 2. Enable USB Debugging on your phone
1. Settings → About Phone → tap "Build Number" 7 times
2. Settings → Developer Options → enable **USB Debugging**
3. Connect phone via USB → tap "Allow" on the prompt
4. Verify: `flutter devices` should list your phone

### 3. Set up Firebase (backend)
This app uses Firebase for auth, database, storage, and messaging.

1. Go to https://console.firebase.google.com → Create project "placement-hub"
2. Add an **Android app** with package name: `com.example.placement_hub`
3. Download `google-services.json` → place inside `android/app/`
4. Enable in Firebase console:
   - **Authentication** → Email/Password
   - **Firestore Database** → start in test mode
   - **Storage** → start in test mode
5. Install FlutterFire CLI and configure:
   ```bash
   dart pub global activate flutterfire_cli
   flutterfire configure
   ```
   This generates `lib/firebase_options.dart` automatically.

### 4. Run the app
```bash
flutter pub get
flutter run
```

The app will install and launch on your USB-connected phone.
